Navigation rules
Every screen carries a ← Back arrow naming its destination, a breadcrumb, a role badge, and ☰ drawer access.

Developers: no screen is more than 2 taps from Hub.
PARTICIPANT FLOW
Splash → Hub → Assignments → Submit Proof → Confirmation
ORGANIZER FLOW
Splash → Hub → Hack Rooms → Create Assignment / Verify
SPOT CHALLENGE FLOW
Organizer pushes → All participants notified → Accept → Submit → Verify
GAMES FLOW
Hub → Responsible Games → Select game → Play → Return to Hub
